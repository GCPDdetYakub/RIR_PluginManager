# RIR_PluginManager для Revit 2027 и Revit 2026.5+

Добавляет кнопку **«Plugin Manager»** на вкладку Rhino.Inside. Кнопка открывает окно, где можно выбрать, какие плагины Grasshopper загружать внутри Revit. Выбор сохраняется в текстовый профиль. Невыбранные плагины временно переименовываются в `*.off` и получают исходные имена обратно сразу после загрузки Grasshopper в Revit (или при закрытии Revit), так что обычный Rhino их снова видит.

## Сборка и установка

### 1. Установить .NET 10 SDK (один раз)

Скачайте **.NET 10 SDK, Windows x64** с https://dotnet.microsoft.com/download/dotnet/10.0. Нужен именно SDK, а не Runtime.

После установки откройте **новое** окно PowerShell и проверьте:

```powershell
dotnet --version
```

Должна быть версия, начинающаяся с `10.`.

### 2. Собрать и установить

1. Закройте Revit.
2. Распакуйте архив, например в `C:\Tools\RIR_PluginManager`.
3. В PowerShell выполните:

```powershell
cd C:\Tools\RIR_PluginManager
powershell -ExecutionPolicy Bypass -File .\install.ps1                      # Revit 2027
powershell -ExecutionPolicy Bypass -File .\install.ps1 -RevitVersion 2026   # Revit 2026.5 и новее
```

Первая сборка скачивает с nuget.org пакет `Lib.Harmony` (`System.Formats.Nrbf` входит в .NET 10), поэтому нужен доступ в интернет.

Скрипт соберёт DLL (в `bin\Release2027\` или `bin\Release2026\`) и скопирует в `%APPDATA%\Autodesk\Revit\Addins\<версия>\` два объекта:

- `RIR_PluginManager.addin` (манифест);
- папку `RIR_PluginManager\` с `RIR_PluginManager.dll` и `0Harmony.dll`.

Если Revit установлен не в `C:\Program Files\Autodesk\Revit 2027`, укажите путь:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -RevitDir "D:\Autodesk\Revit 2027"
```

### 3. Первый запуск

Запустите Revit 2027. Он спросит про неподписанную надстройку: выберите **«Всегда загружать»**.

Кнопка появится на вкладке **Rhino.Inside** справа, на панели «Плагины GH» (кнопка «Plugin Manager»). Если вкладки Rhino.Inside в момент загрузки ещё не было, кнопка окажется на вкладке **«Надстройки»**.

## Как пользоваться

1. Запустите Revit 2027 и нажмите **«Plugin Manager»** до первого открытия Grasshopper в этой сессии.
2. Снимите галочки с плагинов, которые не нужно загружать (сейчас это TTToolbox, Bison и DecodingSpaces). Если навести курсор на строку, появится список её файлов.
3. Выберите действие:
   - **Применить**: только отключить плагины;
   - **Применить → Rhino**: отключить и запустить Rhino;
   - **Применить → Grasshopper**: отключить и сразу открыть Grasshopper;
   - **Отмена**: ничего не менять.

## Проверка плагинов

Кнопка **«Проверить плагины»** запускает проверку (в фоне, окно не блокируется) и ставит у каждого плагина значок. Плагины при этом **не загружаются**: файлы читаются как данные (метаданные .NET), код плагинов не выполняется, поэтому проверка не может уронить Revit.

| Значок | Значение | Что проверяется |
|---|---|---|
| ✖ | плагин не загрузится | Python-компоненты `.ghpy` (IronPython 2.7 не работает на .NET 10) |
| ⚠ | возможны проблемы | код плагина использует `BinaryFormatter` (не будут работать функции, которые к нему обращаются); ресурсы `.gha` в формате `BinaryFormatter`, которые надстройка не умеет восстановить (картинки и иконки восстанавливаются, см. ниже); зависимость от IronPython; плагину нужна более новая версия библиотеки, чем у другого плагина или чем уже загружена в Revit; плагин установлен дважды |

| ℹ | к сведению | плагин собран под .NET Framework 4.x или очень старый |
| ✔ | замечаний нет | — |

Окно оформлено в светлой минималистичной теме (светло-серый фон, графитовый текст, тонкие линии, мягкие тени, чёрное выделение строки, мятные тумблеры вместо галочек); окно перетаскивается за заголовок, закрывается крестиком или Esc. Управление с клавиатуры: ↑/↓ или W/S (в любой раскладке) — перемещение по списку, Enter — включить или выключить выбранный плагин. Легенда значков находится под списком. Подробности по выбранному плагину (щелчок по названию; строка подсвечивается) показываются в панели справа и не меняются при наведении на другие строки: текст можно прокручивать и копировать, ширину панели можно менять, перетаскивая границу. Список сортируется по алфавиту или по результату проверки (сначала ✖, затем ⚠, ℹ, ✔). Результаты проверки целиком записываются в `log.txt`. Кнопки «Снять ✖» и «Снять ✖ и ⚠» снимают галочки с соответствующих плагинов. Это эвристика по известным причинам проблем на .NET 10: плагин без замечаний не гарантированно работает, а плагин с ⚠ может работать нормально.

## Предзагрузка общих библиотек

В одном процессе .NET может быть только одна версия библиотеки с данным именем, и плагину подходит уже загруженная версия, только если она не старше нужной. Если несколько плагинов привозят одну библиотеку в разных версиях (например, `SimpleGrasshopper` 1.4.5 у QuickConnection и 1.8.2 у WiresRenderer), без вмешательства побеждает тот, кто загрузился первым, и плагины, которым нужна более новая версия, не загружаются.

Надстройка сразу после запуска Rhino (до загрузки плагинов Grasshopper) заранее загружает **самую новую** из найденных копий каждой такой библиотеки. Учитываются только DLL включённых плагинов; системные библиотеки .NET и всё, что уже загружено в Revit, не трогаются. В логе — строка на каждую библиотеку: версия, из какого плагина, у каких плагинов старые копии.

В проверке плагинов такой конфликт показывается как ℹ «будет использоваться версия …». Если у старой и новой версии разный основной номер (например, 4.x и 13.x), ставится ⚠: возможна несовместимость. Отдельную библиотеку можно исключить строкой `preload_exclude=Имя` в профиле, всю функцию — галочкой в окне (`preloadshared=false`). Изменения действуют со следующего запуска Rhino.

## Восстановление иконок старых плагинов

Многие плагины хранят иконки в ресурсах в старом формате, который читается только через `BinaryFormatter`, а его в .NET 9+ нет. Надстройка перехватывает чтение таких ресурсов (`ResourceManager.GetObject`) и, если оно упало, сама разбирает данные официальной библиотекой Microsoft `System.Formats.Nrbf` (без выполнения кода плагина), достаёт картинку и возвращает её плагину. Восстанавливаются `Bitmap` и `Icon`; остальные типы ресурсов проходят как раньше.

Итог за сессию пишется в лог строкой `IconFix: восстановлено ресурсов N, не удалось M`. Отключить восстановление можно галочкой в окне надстройки (`iconfix=false` в профиле), изменение действует после перезапуска Revit.

Это не возвращает `BinaryFormatter` целиком: плагины, которые используют его в своём коде для данных (например, TTToolbox), по-прежнему помечаются ✖.

Кнопка **«Grasshopper (профиль)»** рядом делает то же, что «Применить → Grasshopper», но без окна: применяет сохранённый профиль и открывает Grasshopper. Используйте её вместо штатной кнопки Grasshopper: на Revit 2027 запуск через штатную кнопку после Start в ряде случаев приводит к крашу, а этот путь работает стабильно.

Галочка **«Применять профиль автоматически при запуске Revit»** делает так, что профиль применяется сам при каждом старте Revit. Тогда можно сразу нажимать штатную кнопку Grasshopper, не открывая окно.

## Файлы

Все файлы лежат рядом с DLL, в `%APPDATA%\Autodesk\Revit\Addins\<версия Revit>\RIR_PluginManager\` (открывается кнопкой «Папка профиля»). Профиль и список переименований из старой папки `%APPDATA%\RirPluginManager\` (версии 1.0–1.2) переносятся туда автоматически при первом запуске Revit.

| Файл | Назначение |
|---|---|
| `profile-revit<версия>.txt` | Профиль: `autoapply`, `iconfix` и строки `disabled=Источник\|Имя`. Имя берётся из версии запущенного Revit (`profile-revit2026.txt`, `profile-revit2027.txt`). Если в папке лежит профиль с другим номером (например, скопированный из папки 2027), при запуске он переименовывается под текущую версию. Можно редактировать вручную. |
| `renamed.txt` | Какие файлы сейчас переименованы. Используется для восстановления. |
| `folders.txt` | Необязательный. Дополнительные папки с плагинами, по одной на строку (например, папки из GrasshopperDeveloperSettings). |
| `logs\log_ГГГГ-ММ-ДД_чч-мм-сс.txt` | Отдельный лог на каждый запуск Revit; хранятся **5 последних**, при новом запуске самый старый удаляется. В логе: версии надстройки, .NET и Revit, применение и восстановление профиля, результаты проверки плагинов, итог восстановления иконок, полные стеки исключений загрузки плагинов (`FileLoadException`, `TypeLoadException` и др.). Один лог ограничен 20 МБ. Прежний общий `log.txt` при первом запуске переносится в эту папку. |

По умолчанию сканируются:

- `%APPDATA%\Grasshopper\Libraries`
- `%APPDATA%\McNeel\Rhinoceros\packages\8.0`

## Ограничения

- Надстройку нужно устанавливать для текущего пользователя (`%APPDATA%`), как делает `install.ps1`: профиль хранится рядом с DLL, и папка должна быть доступна для записи.
- После загрузки плагинов Grasshopper их нельзя выгрузить. Чтобы сменить набор, нужен перезапуск Revit.
- Файлы возвращаются автоматически через несколько секунд после того, как Grasshopper загрузился в Revit: дальше они не нужны, потому что GH не перечитывает папки до перезапуска Revit. Отдельный Rhino не увидит отключённые плагины только в промежутке между применением профиля и загрузкой GH в Revit. В этот промежуток имена можно вернуть кнопкой «Вернуть все файлы».
- Если Revit упадёт, имена файлов вернутся при следующем запуске Revit (если включено автоприменение, профиль после этого сразу применится снова). Вернуть имена без Revit можно скриптом `restore.ps1`: `powershell -ExecutionPolicy Bypass -File .\restore.ps1`.
- Отключённые этим аддоном плагины показываются в списке с пометкой «сейчас отключён». Кнопка «Вернуть все файлы» возвращает имена, не меняя профиль.
- Если открыто несколько экземпляров Revit (в том числе 2026 и 2027 одновременно), первый закрытый вернёт имена файлов для всех.
- Идентификаторы команд Rhino.Inside взяты из RiR 1.35. Если в будущей версии RiR они изменятся, кнопки «→ Rhino» и «→ Grasshopper» сообщат об этом, а отключение плагинов продолжит работать.

## Удаление

Закройте Revit и выполните (скрипт сначала вернёт имена отключённым плагинам, затем удалит надстройку вместе с профилем):

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1                      # Revit 2027
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -RevitVersion 2026
```

## Переименование (с версии 1.11)

Надстройка называется **RIR_PluginManager** (раньше RirPluginManager). `install.ps1` сам переносит профиль и список отключённых файлов из старой папки `Addins\<версия>\RirPluginManager` и удаляет старую установку. При ручной установке старые `RirPluginManager.addin` и папку `RirPluginManager` нужно удалить, иначе Revit загрузит обе надстройки и сообщит о повторяющемся AddInId.
